# FenceLine Florida

Vinyl and chain-link fence installation (residential & commercial) for Jacksonville & Central Florida (Orange, Seminole, Osceola County). Built with Next.js + Relume.

## SEO / AEO / Voice

- **Sitewide rules (SEO + voice — required for all templates):** [`docs/seo-sitewide-rules.md`](docs/seo-sitewide-rules.md)
- **Shared entity + meta + JSON-LD helpers:** [`lib/seo-entity.js`](lib/seo-entity.js)
- Homepage brief: `docs/fenceline-florida-seo-aeo-implementation-brief.md`

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
