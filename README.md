# FenceLine Florida

Vinyl and chain-link fence installation (residential & commercial) for Jacksonville, Orlando, and Kissimmee. Built with Next.js + Relume.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Live

https://fencelineflorida.com

## Brand

Edit `lib/site.js` for phone, email, address, and site name.
